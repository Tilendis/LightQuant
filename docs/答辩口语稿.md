## 0. 开场（30 秒）

你说：
"这是我做的股票趋势研判与策略回测系统。
简单说就是：系统自动从三个角度判断股票涨跌——技术面、基本面、情绪面，
然后把三个角度的结论融合成一个综合判断，
再用这个判断去跑模拟交易，看能赚多少、回撤多大。
系统里有四种角色：投资者、策略作者、风控员、运营，权限是分开的。"

红三角是看多，绿三角是看空，不同颜色代表不同视角。"

（指着下面的表格）

你说：
"下面这张表是四个视角各自的判断结果。
技术面是用本地训练的一个神经网络（BiLSTM），吃量价数据；
基本面是看估值分位，PE/PB 在历史上的位置；
情绪面是大模型读当天新闻，打一个分。
三个视角是独立的，不是同一段提示词换个名字。"

## 2. 策略回测页（切到"回测"标签）

你说：
"这个页面是回测。我选一只股票、选一段时间、选止盈止损参数，
点提交，系统后台跑一遍模拟交易，然后画出净值曲线。"

（等回测跑完，指着净值图）

你说：
"这条线是策略净值，红色阴影是最大回撤区间，
上面那些小点点是买卖点。
现在主口径的结果是：四个半月累计赚 7.9%，最大回撤 2.78%，夏普 2.24。
同期买入持有基准涨了 19.04%，我们跑输了——这个我自己先说。
跑输的原因是这段时间市场单边上涨，我们信号比较保守，仓位暴露少。
但好处是回撤小，基准回撤 9.74%，我们只有 2.78%。"

## 5. 运营看板（切到"看板"标签）

技术面准确率大概 52.5%，基本面 49.4%，情绪面 50.5%，融合后 52.4%。
融合并没有比最强的单视角好多少——这个我也自己说。
系统的价值不是'融合更准'，是三个视角可以独立跑、独立评估、独立关掉，
能看出来哪个视角在这段行情里失效了。"

## 6. 可能被问的难问题（提前准备）

**问：你这个系统跑输基准，有什么意义？**

你说：
"毕设不是对冲基金，不要求跑赢基准。
系统做的是：多视角研判 → 融合 → 回测 → 跟单 → 风控，整条链路跑通了。
而且我修了两处口径问题——一处是标准化参数原来在测试段上算的，
相当于预测时偷看了未来；另一处是旧主口径里有一段技术面没跟着重算，
还留着修复前的数据。修完数字变差了（从 15.97% 降到 7.9%），
但口径是干净的，这个我觉得比数字好看重要。"

**问：基本面权重为什么是 0？**

你说：
"权重是在验证集上网格搜索出来的。
基本面权重从 0 加到 1，验证集准确率反而降了 5.4 个百分点，
所以系统自动把它压到 0 了。
这不是'基本面没用'，是'系统能判断哪个视角在这段行情里不可信'。"

**问：四个角色权限怎么控制的？**

你说：
"每个接口后端都校验角色，不是前端藏按钮。
比如投资者直接调风控接口，后端会返回 403。
selftest 里有 8 项专门测越权路径。"
