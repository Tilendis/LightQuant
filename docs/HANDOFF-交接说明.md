## 5. 对照实验结论（最新配对口径，详见 `docs\消融与改进实验记录.md`）

> 所有实验脚本在 `scripts\`，离线现算，不动主口径。

### 5.1 消融（单版本配对，四视角交集 871 格）

主版本：tech-v1 / fund-rule-v1 / sent-v1 / fusion-test-3view-v2。

| 视角 | ACC | Brier |
| --- | ---: | ---: |
| tech | 0.4983 | 0.2645 |
| fund | 0.5132 | 0.3537 |
| sent | 0.5063 | 0.2971 |
| fusion | 0.5040 | 0.2601 |

配对 871 格上融合（0.5040）**低于最强单视角 fund（0.5132）0.92pp**，与 tech 的差 +0.57pp；两组差值都在 1 个二项标准误（1.69pp）以内，均不显著。fusion Brier 最优（0.2601），fund Brier 最差，与验证集权重置 0 自洽。

全量口径（各视角各自全样本）：tech 0.5060 / fund 0.4940 / sent 0.5054 / **fusion 0.5114**，融合较 tech 高 0.54pp，同样不显著。**结论：融合不提升分类精度，其价值在回测风险收益结构与可独立开关的机制上。**

### 5.2 可靠性校准（isotonic，val 拟合 / test 验证）

校准只改概率映射、不改方向排序，ACC 基本持平，Brier/ECE 下降；fund、sent 校准误差下降最明显。明细见实验记录第 2 节。

### 5.3 自适应权重（tech/fund 对齐 n=4650，窗口 20 交易日）

| 口径 | ACC | Brier |
| --- | ---: | ---: |
| 固定 0.9/0/0.1 | 0.5069 | 0.2591 |
| 滚动命中率动态 | 0.5288 | 0.2671 |
| Δ | +0.0219 | +0.0080 |

结论：ACC 升但 Brier 恶化，93 个样本外交易日不足以稳定估计行情状态；**不得写成"动态调权更优"**。

### 5.4 权重稳定性（val 切前后两半网格搜权）

> 这一组的 ACC 台账来自 v1 融合口径（12 月 tech 修复前），权重的**方向性结论**（fund 两半均为 0）不受影响，但具体 ACC 数字引用时须注明口径。

前半 0.7/0/0.3 ACC 0.5722；后半 0.8/0/0.2 ACC 0.5522；全 val 0.8/0/0.2 ACC 0.5592；主口径固定 0.9/0/0.1 ACC 0.5581。fund 权重两半均为 0，稳定；tech/sent 小幅波动，ACC 对权重不敏感。

### 5.5 成本敏感性（固定 616 笔交易序列，v2 主口径）

| 情景 | 总费用(元) | 累计收益 | Sharpe | MDD |
| --- | ---: | ---: | ---: | ---: |
| 0 费率（理想，不可执行） | 3080.00 | 8.80% | 2.513 | 2.61% |
| 1x 现状 | 49509.17 | 7.87% | 2.246 | 2.79% |
| 2x（压力） | 99018.33 | 6.88% | 1.956 | 2.99% |
| 3x（压力） | 148527.50 | 5.89% | 1.662 | 3.18% |

费用规则：佣金双边万三、最低 5 元/笔；印花税千一仅卖出端；滑点万五已计入成交价不重复扣。**1x 成本侵蚀 0.93pp**（8.80% → 7.87%，与主口径 summary 7.90% 仅差 0.03pp，口径已对齐）。分母为总本金 500 万（10 万 × 50 账户），早期版本的"64.14% / −49.14%"是误用单账户本金作分母，已作废。

## 6. 红线与口径禁令（答辩/论文最容易翻车处）

- 禁说："融合全面提升""三视角无条件优于单视角""系统已完成""动态调权更优"。
- 融合结论：机制完备、可切换，但**不宣称融合提升分类精度**。全量 0.5114 vs tech 0.5060（+0.54pp）、配对 0.5040 vs fund 0.5132（−0.92pp），两个差值都小于 1 个二项标准误。融合的可陈述价值是回测风险收益结构（7.90% / 夏普 2.236 vs 纯技术面 5.73% / 1.720）。
- fund 权重为 0 是验证集数据驱动的客观结论，且已用两条通道验证：估值分位（网格 0→1 单调下降、选池降夏普）与财务质量分（ACC 0.4911、RankIC −0.0149、97 日内平均只跳变 0.78 次）。**原因是季频信息与日频任务频率失配，不是指标选错。**
- **禁止再写"成本侵蚀"叙事**：实测成本只侵蚀 0.93pp，"跑输基准是因为交易成本"是错误归因。跑输 11.14pp 的原因是单边上涨段信号敞口不足与频繁换手的弹性损失。
- 分样本结论必须附样本量提示（40~50 交易日 × 50 标的，提示性观察，非统计显著）。
- 不可引用：测试集 MCC 加权 54.09%（权重取自测试集，泄漏）；`summary.json` 字段名是 `arr` / `ir_vs_equal_weight`，没有 `annual_return` / `ir`。
- **不可引用旧主口径 9.36% / ACC 0.5236 / 夏普 2.673 / 733 笔**：那是 `fusion-test-3view`（12 月 tech 为修复前数据）的数字，已作废，改用 `test_fusion_3view_v2` 的 7.90% / 0.5114 / 2.236 / 616 笔。
- 情绪面 ACC 只在 920 个当日有新闻的格上算，不能说"情绪面全样本有效"；**也不能说"没做时间衰减是缺陷"**——衰减 3 天 / 10 天的实测都更差。
- 研究层 threshold=0.2 与回测 `--score_th 0.0` 是两个口径，不要混表。
- 旧文档注意：`docs\第5章实验数据表.md` 的表 5-3/5-4/5-5、`docs\工程化收尾说明.md` 第七节部分数字是前视泄漏修复前的旧口径，论文阶段须按第 3 节主口径更新，不要直接抄旧数。
