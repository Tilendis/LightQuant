## 5. 对照实验结论（最新配对口径，详见 `docs\消融与改进实验记录.md`）

> 所有实验脚本在 `scripts\`，离线现算，不动主口径。

### 5.1 消融（单版本配对，四视角交集 871 格）

主版本：tech-v1 / fund-rule-v1 / sent-v1 / fusion-test-3view。

| 视角 | ACC | Brier |
| --- | ---: | ---: |
| tech | 0.4983 | 0.2645 |
| fund | 0.5121 | 0.3537 |
| sent | 0.5075 | 0.2971 |
| fusion | 0.5144 | 0.2557 |

融合相对最强单视角仅 **+0.23pp**，未形成显著优势；fusion Brier 最优。fund Brier 最差，与验证集权重置 0 自洽。

### 5.2 可靠性校准（isotonic，val 拟合 / test 验证）

校准只改概率映射、不改方向排序，ACC 基本持平，Brier/ECE 下降；fund、sent 校准误差下降最明显。明细见实验记录第 2 节。

### 5.3 自适应权重（tech/fund 对齐 n=4650，窗口 20 交易日）

| 口径 | ACC | Brier |
| --- | ---: | ---: |
| 固定 0.9/0/0.1 | 0.5069 | 0.2591 |
| 滚动命中率动态 | 0.5288 | 0.2671 |
| Δ | +0.0219 | +0.0080 |

结论：ACC 升但 Brier 恶化，93 个样本外交易日不足以稳定估计行情状态；**不得写成"动态调权更优"**。

### 5.4 权重稳定性（val 切前后两半网格搜权）

前半 0.7/0/0.3 ACC 0.5722；后半 0.8/0/0.2 ACC 0.5522；全 val 0.8/0/0.2 ACC 0.5592；主口径固定 0.9/0/0.1 ACC 0.5581。fund 权重两半均为 0，稳定；tech/sent 小幅波动，ACC 对权重不敏感。

### 5.5 成本敏感性（固定 733 笔交易序列）

| 情景 | 总费用(元) | 累计收益 | Sharpe |
| --- | ---: | ---: | ---: |
| 0 费率（理想，不可执行） | 3665.00 | 64.14% | 13.066 |
| 1x 现状 | 58471.84 | 9.34% | 2.685 |
| 2x（压力，失真） | 116943.69 | -49.14% | -14.767 |
| 3x（压力，失真） | 175415.53 | -107.61% | 0.307 |

费用规则：佣金双边万三、最低 5 元/笔；印花税千一仅卖出端；滑点万五已计入成交价不重复扣。2x/3x 本金耗尽后线性口径失真，仅展示成本侵蚀趋势。

### 5.6 撮合口径对照（标题必须写"口径差异对照"，不做策略优劣对比）

| 项 | 择时 engine_v2 | 截面 engine_cross_section |

| 撮合时点 | T 日收盘算分 + 收盘集合竞价成交 | T-1 收盘算分 + T 日开盘成交 |

### 5.7 发帖审核规则层评测（24 条标注集，四类各 6）

规则层 P=1.000、R=0.500、F1=0.667；关键词违规零漏拦、正常/边界零误拦；6 条语义违规规则层放行，由 LLM 层兜底。LLM 层本地无 key，串联 P/R/F1 待配 key 复测。边界帖处置：默认放行，进 LLM/人工复审队列。

## 6. 红线与口径禁令（答辩/论文最容易翻车处）

- 禁说："融合全面提升""三视角无条件优于单视角""系统已完成""动态调权更优"。
- 融合结论：机制完备、可切换，但不宣称融合提升预测能力；融合 ≈ 最强单视角。
- fund 权重为 0 是验证集数据驱动的客观结论（负 IC），不是缺数据；降级为风险描述与选池参考。
- 跑输基准 9.68pp 要正面写：前视泄漏修复后预测能力回归理性区间，叠加 A 股双边佣金/印花税/滑点，高换手摩擦侵蚀微弱优势，符合半强式有效市场规律。
- 分样本结论必须附样本量提示（40~50 交易日 × 50 标的，提示性观察，非统计显著）。
- 不可引用：测试集 MCC 加权 54.09%（权重取自测试集，泄漏）；`summary.json` 字段名是 `arr` / `ir_vs_equal_weight`，没有 `annual_return` / `ir`。
- 情绪面 ACC 只在 920 个当日有新闻的格上算，不能说"情绪面全样本有效"。
- 研究层 threshold=0.2 与回测 `--score_th 0.0` 是两个口径，不要混表。
- 旧文档注意：`docs\第5章实验数据表.md` 的表 5-3/5-4/5-5、`docs\工程化收尾说明.md` 第七节部分数字是前视泄漏修复前的旧口径，论文阶段须按第 3 节主口径更新，不要直接抄旧数。
