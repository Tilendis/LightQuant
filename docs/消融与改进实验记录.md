# 消融与改进实验记录（离线分析，不替换主口径）

> 数据来源：judgements + prices，test 段 2024-08-08 ~ 2024-12-31。
> 红线：校准模型只在 val 段（2024-03-15 ~ 08-07）拟合，test 段只做验证；动态权重滚动窗口只用过去 20 个交易日历史。主口径回测数字不受这些实验影响。
> 脚本：`scripts/ablation_experiment.py`、`scripts/calibration_experiment.py`、`scripts/dynamic_weight_experiment.py`

## 1. 三视角消融（test 段）

| 视角 | 样本数 | ACC | Brier |
| --- | ---: | ---: | ---: |
| tech（本地 BiLSTM） | 7450 | 0.5101 | 0.2616 |
| fund（估值分位规则） | 7026 | 0.4973 | 0.3274 |
| sent（新闻文本） | 981 | 0.5036 | 0.2932 |
| fusion（加权融合） | 21692 | 0.5247 | 0.2601 |

融合相对最强单视角（tech）ACC 仅 +1.46pp，未形成显著优势；fund ACC 接近随机、Brier 最差，与验证集权重标定为 0 的结论一致。

### 分样本 ACC（提示性观察，子样本仅 40~50 交易日 × 50 标的，差异需更长区间验证）

| 区间 | tech | fund | sent | fusion |
| --- | ---: | ---: | ---: | ---: |
| 8-9 月上涨段 | 0.4575 | 0.4865 | 0.5373 | 0.4844 |
| 10-11 月震荡段 | 0.5687 | 0.5260 | 0.4439 | 0.5604 |
| 12 月 | 0.5023 | 0.4833 | 0.5575 | 0.5251 |

不同行情下各视角强弱互换：tech 在震荡段占优，sent 在上涨段占优。这是"单一模型存在认知偏差、多视角互补"的提示性证据，但受样本量限制，不作为统计显著结论。

## 2. 可靠性校准改进（isotonic 回归，val 拟合 / test 验证）

| 视角 | 口径 | ACC | Brier | ECE |
| --- | --- | ---: | ---: | ---: |
| tech | 校准前 | 0.5015 | 0.2625 | 0.0668 |
| tech | 校准后 | 0.5015 | 0.2605 | 0.0438 |
| fund | 校准前 | 0.4938 | 0.3286 | 0.2171 |
| fund | 校准后 | 0.5113 | 0.2507 | 0.0299 |
| sent | 校准前 | 0.5041 | 0.2931 | 0.1792 |
| sent | 校准后 | 0.5133 | 0.2526 | 0.0506 |
| fusion | 校准前 | 0.5173 | 0.2608 | 0.0465 |
| fusion | 校准后 | 0.5126 | 0.2543 | 0.0345 |

- isotonic 校准只改善概率映射，不改变方向排序，因此 ACC 基本持平，Brier 与 ECE 下降。
- fund/sent 的校准误差下降最明显（fund ECE -0.187，sent ECE -0.129）：原始分数的过度自信主要来自概率映射不当，而非方向排序错误。
- fund 校准后概率被压回 0.4~0.6 区间，印证其在样本内无区分度。

## 3. 自适应权重对照（固定权重 vs 滚动命中率动态权重，n=4650，窗口 20 交易日）

| 口径 | ACC | Brier |
| --- | ---: | ---: |
| 固定权重 0.9/0/0.1 | 0.5224 | 0.2541 |
| 滚动命中率动态权重 | 0.5366 | 0.2622 |
| Δ（动态-固定） | +0.0142 | +0.0080 |

动态权重方向 ACC +1.42pp，但 Brier 恶化 0.008：短期命中率估计噪声较大，动态调权引入了额外方差。93 个样本外交易日不足以稳定估计行情状态，权重对样本敏感；后续应采用更长窗口、命中率收缩正则化或滚动标定，本实验不替换主口径固定权重。

## 4. 论文口径注意

- 主口径仍是"修复前视泄漏后的诚实回测结果"；上述实验属于"基于诊断的改进尝试"，叙事顺序不能反。
- fund=0、融合≈单视角、跑输基准、sent 覆盖率 19% 均作为实验发现正面陈述，配套改进方向见结论与局限章节。
- 分样本结论必须附样本量提示，不得表述为统计显著。

## 5. 权重稳定性检验（val 段切前后两半，网格搜权重）

脚本：`scripts/weight_stability.py`。val 段 98 个交易日，以 2024-05-30 为界切前后两半，分别在 tech/fund/sent 权重网格（步长 0.1）上搜最优 ACC。

| 区间 | 样本数 | 最优 tech/fund/sent | ACC |
| --- | ---: | ---: | ---: |
| 前半 03-15 ~ 05-30 | 2092 | 0.7 / 0.0 / 0.3 | 0.5722 |
| 后半 05-30 ~ 08-08 | 2450 | 0.8 / 0.0 / 0.2 | 0.5522 |
| 全 val | 4542 | 0.8 / 0.0 / 0.2 | 0.5592 |
| 主口径固定 0.9/0/0.1 | 4542 | 0.9 / 0.0 / 0.1 | 0.5581 |

- fund 权重在两半均为 0，结论稳定，与 fund 无预测力自洽。
- tech/sent 权重在 0.7~0.8 / 0.2~0.3 间小幅波动；主口径 0.9/0/0.1 与全 val 最优 ACC 仅差 0.11pp，ACC 对权重取值不敏感。
- 表述口径：静态标定在小样本上存在轻微敏感性，后续可采用滚动标定；本实验不替换主口径权重。

## 6. 成本敏感性表（固定交易序列，733 笔）

脚本：`scripts/cost_sensitivity.py`。沿用主口径 `test_fusion_3view` 的买卖点、股数与成交价，仅调整佣金与印花税倍数；滑点已计入成交价，不重复扣除。费用规则：佣金双边万三、最低 5 元/笔；印花税千一、仅卖出端。

| 情景 | 笔数 | 总费用(元) | 累计收益 | Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0 费率（零成本） | 733 | 3665.00 | 64.14% | 13.066 | 0.96% |
| 1x（现状：佣金万三 + 印花税千一） | 733 | 58471.84 | 9.34% | 2.685 | 2.79% |
| 2x（佣金印花税翻倍） | 733 | 116943.69 | -49.14% | -14.767 | 48.66% |
| 3x（佣金印花税三倍） | 733 | 175415.53 | -107.61% | 0.307 | 106.67% |

- 1x 重算与主口径 summary 对照：cum 9.34%（主口径 9.36%）、Sharpe 2.685（2.673）、总费用 58471.84（58471.88），口径一致。
- 零成本到现状，费用侵蚀约 54.8pp 累计收益：高换手策略在 A 股双边摩擦下利润被交易成本大幅吃掉，这是策略跑输等权基准的重要原因之一，属行业常态。
- 2x/3x 为压力情景：费用累计超过本金后，线性扣减口径下净值为负，Sharpe 与回撤指标失真，仅用于展示成本侵蚀趋势，不作为可执行结果。
- 净值口径：费用为现金一次性流出，按发生日线性扣减权益，不按比例复利缩减后续持仓市值。

## 7. 撮合时点口径差异对照

脚本：`scripts/matching_basis_compare.py`。两套引擎信号来源、仓位口径、换手频率均不同，下表只并列口径与指标，不做"哪种策略收益更高"的结论对比。

| 对照维度 | 择时引擎 engine_v2 | 截面引擎 engine_cross_section |
| --- | --- | --- |
| 撮合时点假设 | T 日收盘算分，T 日收盘集合竞价成交 | T-1 收盘算分，T 日开盘成交（剔除隔夜跳空） |
| 价格口径 | 未复权收盘价 close | 未复权开盘价 open（信号用 T-1 收盘） |
| 仓位口径 | 单票独立资金、等权持有 | 组合口径，Top-N 等权、固定持有期再平衡 |
| 信号来源 | 三视角融合分数 | 技术面单视角截面排序 |
| 调仓频率 | 逐日信号触发，T+1 不可当日卖出 | 每 5 个交易日再平衡一次 |
| 样本区间 | 2024-08-14 ~ 2024-12-31 | 2024-08-08 ~ 2024-12-31 |
| 累计收益 | 9.36% | 53.80% |
| Sharpe | 2.673 | 3.676 |
| 最大回撤 | 2.78% | 5.29% |
| 成交笔数 | 733 | 370 |
| 总费用(元) | 58471.88 | 4280.74 |
| 佣金/印花税/滑点 | 万三 / 千一(卖出) / 万五 | 万三 / 千一(卖出) / 千二 |

对照目的：系统同时实现两种撮合时点假设。择时引擎的收盘成交为乐观口径（论文需注明"T 日收盘信号假设收盘集合竞价成交"）；截面引擎的 T-1→T 开盘成交为更保守的可执行口径。两表累计收益不可直接比较。

## 8. 发帖审核规则层评测

脚本：`scripts/moderation_eval.py`；标注集：`scripts/moderation_samples.json`（24 条，四类各 6 条）。

| 类别 | 样本 | TP | FP | FN | TN |
| --- | ---: | ---: | ---: | ---: | ---: |
| normal 正常讨论 | 6 | 0 | 0 | 0 | 6 |
| keyword_violation 关键词违规 | 6 | 6 | 0 | 0 | 0 |
| semantic_violation 语义违规 | 6 | 0 | 0 | 6 | 0 |
| borderline 边界擦边 | 6 | 0 | 0 | 0 | 6 |

整体（正类=BLOCKED）：精确率 P=1.000，召回率 R=0.500，F1=0.667；混淆矩阵 TP=6、FP=0、FN=6、TN=12。

- 规则层三类正则（承诺收益 / 诱导加群 / 代客理财）对关键词违规零漏拦、对正常与边界样本零误拦。
- 6 条语义违规无规则词，规则层放行，属预期漏判，设计上由 LLM 层兜底。
- LLM 层本地未配置 MODERATOR_PROVIDER 与对应 key，本轮未参与评测；规则+LLM 串联的 P/R/F1 待配置后复测。论文表述为"规则层 + LLM 层两级管线设计，规则层离线评测通过，LLM 层评测样本量受限"。
