# 第 5 章 实验数据表

数据集 CSMD50，50 只 A 股；时间切分 train ≤ 2024-03-14 / val 2024-03-15~08-07 / test 2024-08-08~12-31。标签 `Label = Close(t+1) > Close(t)`，即次日方向。

## 表 5-1　特征维度在不同架构上的表现（测试集）

| 架构 | 特征维度 | 种子数 | 测试集 ACC | 相对同架构五维基线 | 结果目录 |
|---|---|---:|---:|---:|---|
| ALSTM | 五维（默认） | 3 | 53.30% ± 0.54 | — | `result/base_alstm_s{43,101,2024}` |
| ALSTM | 十维 | 3 | **54.84% ± 0.13** | **+1.54pp**（Welch t=4.81，p<0.01） | `result/exp_feat_alstm_s{43,101,2024}` |
| BiLSTM | 五维（默认） | 3 | 53.71% ± 0.94 | — | `result/CSMD50_w5_nols_bi_lstm` + `_s{43,101}` |
| BiLSTM | 十维 | 3 | **54.82% ± 0.17** | **+1.10pp**（Welch t=−2.00，p=0.175，n=3 下不显著） | `result/CSMD50_w5_feat_bi` + `exp_feat_bi_s{43,101}` |

± 为三个种子的样本标准差（n−1）。

**读法**：十维特征在两种独立架构上收敛到 0.02pp 以内（54.84 vs 54.82），说明增益来自特征而非某个架构的偶然；同一组特征把两个起点不同的基线（ALSTM 53.30 / BiLSTM 53.71）都抬到 54.8% 附近，提示该数据集在该任务上的判别上限约在 54.8% 附近。

**BiLSTM 五维逐种子**（补种子后新增，供复核）：ACC 0.5460 / 0.5381 / 0.5273；MCC 0.0884 / 0.0720 / 0.0495；F1 0.4687 / 0.4023 / 0.2946。早停轮次 seed37 为 **epoch 90**（`result/CSMD50_w5_nols_bi_lstm/run_log.txt` 可查）；seed43 与 seed101 的当轮日志未落盘留档，早停轮次不作陈述。

**注意**：BiLSTM 五维已补齐到 3 个种子，与十维版构成 n=3 vs n=3 对照，但 Welch 检验 p=0.175 仍不显著——n=3 的统计效力很低，**BiLSTM 组的 +1.10pp 只能作描述性陈述**。显著性结论以 ALSTM 组为准（三种子、t=4.81、p<0.01）。另外五维三种子方差达 ±0.94pp，说明原先把单种子 54.60% 当作"五维基线"会系统性高估该基线。

## 表 5-1b　四个五维模型的三种子稳定性（测试集，n=3）

| 模型 | 种子集 | ACC 均值 ± 标准差 | MCC 均值 ± 标准差 | F1 均值 ± 标准差 |
|---|---|---|---:|---:|---:|
| LSTM | 37 / 43 / 101 | 53.42% ± 0.28 | 0.0634 ± 0.0060 | 0.4082 ± 0.0321 |
| BiLSTM | 37 / 43 / 101 | **53.71% ± 0.94** | 0.0700 ± 0.0195 | 0.3885 ± 0.0878 |
| ALSTM | 43 / 101 / 2024 | 53.30% ± 0.54 | 0.0610 ± 0.0116 | 0.3749 ± 0.0521 |
| AdvLSTM | 37 / 43 / 101 | 52.60% ± 0.62 | 0.0453 ± 0.0153 | 0.3095 ± 0.0500 |

± 为三个种子的样本标准差（n−1）。**四个模型的种子集不完全一致**：LSTM / BiLSTM / AdvLSTM 为本轮补到 37 / 43 / 101，ALSTM 沿用既有 43 / 101 / 2024 口径（`result/seeds_summary.json`），因此只比均值区间，**不做逐种子配对检验**。

**读法**：四个模型的真实能力区间是 52.60–53.71%，跨度 1.11pp；按单种子排序时跨度是 1.59pp（AdvLSTM 53.01 → BiLSTM 54.60），补种子后差距收窄。AdvLSTM 波动最大（±0.62pp）且均值最低，其 F1 在种子间从 0.2566 到 0.3559，说明对抗训练在该数据集上不稳定。

**对"最强基线"叙事的修正**：单种子叙事里 BiLSTM seed37 的 54.60% 是四个成员中的最高抽样；补到三种子后 BiLSTM 53.71% ± 0.94 仍是最高的均值，但对 LSTM 53.42 只领先 0.29pp，不再是压倒性的"最强"。

## 表 5-1c　同构集成与成员均值的对照（测试集）

| 参照 | ACC | 集成 − 参照 |
|---|---:|---:|
| 四模型概率平均 `avg4_lstm_bi_alstm_adv`（成员全为 seed37 权重） | 54.04% | — |
| 同批 seed37 成员均值（53.7419 / 54.6022 / 53.3118 / 53.0108） | 53.67% | **+0.38pp** |
| 四模型三种子成员均值（53.42 / 53.71 / 53.30 / 52.60） | 53.26% | **+0.78pp** |
| seed37 中最高单成员（BiLSTM 54.60%） | 54.60% | **−0.56pp** |

**读法**：同构集成相对成员均值确有小幅增益（两个参照分别为 +0.38pp 与 +0.78pp），但低于 seed37 里运气最好的单个成员 0.56pp。因此既不能写"同构集成净亏"，也不能写"集成提升了预测能力"；准确表述是**集成增益小于种子抽样波动范围（±0.94pp），不能稳定超过最好的单个成员**——这是本文不把同构集成作为主推方案的依据。

**注意**：集成结果只有 seed37 权重一套，未做"成员各自多种子再集成"，故上表是量级对照而非同分布检验。`ensemble_result.json` 里 `mcc_weighted`（54.09%）的权重由 test MCC 反推、`avg3_threshold_sweep` 的阈值取自 test，均为泄漏口径，**不得引用**。逐种子原始值与集成重算见 `docs/exp_multiseed_four_models_w5.json`。

## 表 5-6　情绪面信号时效分布（测试期，50 只 × 97 个交易日 = 4850 格）

| 距最近新闻的间隔 | 单元格数 | 占比 |
|---|---:|---:|
| 当日有新闻 | 920 | 18.97% |
| 1–3 天 | 984 | 20.29% |
| 4–7 天 | 861 | 17.75% |
| **8 天以上** | **1896** | **39.09%** |
| 无任何历史新闻 | 189 | 3.90% |
| 最长间隔 | 66 天 | — |

研判记录共 1046 条，覆盖 143 个日历日，其中 97 个交易日、46 个非交易日（周六 21 / 周日 19 / 节假日 6）。

**结论**：46 条非交易日记录**不是脏数据**——周末与节假日确有新闻发布，按新闻日落库、融合时 ffill 到下一交易日，是事件型数据的正确处理，不删不改。近四成单元格使用 8 天以上、最长 66 天前的判断，这是覆盖结构的事实。

**衰减实验的判定（本轮新增）**：曾预期"给 ffill 加半衰期衰减可改善"，实测相反——半衰期 10 天累计 6.49% / 夏普 1.900，半衰期 3 天 6.04% / 1.797，均低于不衰减的 7.90% / 2.236；ACC 同样下降（0.5077 / 0.5060 vs 0.5114）。因此保留不衰减口径，并把情绪面理解为"持续状态"而非"事件冲击"。详见 `docs/情绪面衰减实验.md`。

**为什么不在测试集上调参**：验证期（03-15~08-07）新闻语料稀疏，无法可靠标定衰减参数；且衰减形式本身属于超参，在测试期上选择同样构成泄漏。本轮的 3 天 / 10 天半衰期取自常用经验值（新闻半衰期 3~10 天），不做测试集搜索。

## 禁用与口径（写正文前必读）

| 易错点 | 正确做法 |
|---|---|
| 字段名 | `summary.json` **没有** `annual_return` / `ir`，用 **`arr`** / **`ir_vs_equal_weight`**；按旧名取会得 None |
| 年化收益 | `arr` 是几何年化，不是"累计收益 ÷ 天数 × 365"，不要自己换算 |
| 测试集 MCC 加权 54.09% | **绝对不可引用**，该权重取自测试集，是泄漏 |
| 验证集指标 | 验证段用于早停与阈值校准，不是完全样本外，必须注明 |
| view_accuracy | 测试期在训练语料覆盖内，只作四视角横向比较，不作有效性证据 |
| 情绪面准确率 | n=920，仅当日有新闻的单元格；不要说"情绪面全样本 50.54%" |
| 融合结论 | 融合 0.5114 vs 技术面 0.5060（+0.54pp，不足 1 个标准误）；配对样本上还低于 fund。可以说机制完备、可切换，不能说融合提升分类精度 |
| 阈值 | 研究层 threshold=0.2 与回测 `--score_th 0.0` 是两个口径，不要混表 |
| 止损 | `api_tech` 的 5% 止损触发 65 次；其余三条为 0，对比时要说明参数不同 |
| 交易成本 | `total_fee` 是 50 个账户的合计，不是单账户手续费 |
| BiLSTM 五维 | 只有单种子，不能做配对显著性检验 |

## 复现命令

```powershell
# 十维 BiLSTM 补种子（seed 43 / 101，各约 3–4 小时 CPU）
python run.py --config configs/exp_feat_bi.yaml --seed 43 `
  --model_save_folder result/exp_feat_bi_s43/model_saved/ `
  --figure_save_folder result/exp_feat_bi_s43/figure/ `
  --test_result_save_folder result/exp_feat_bi_s43/test_result/

# 验证集下跌市回测（注意必须传 --start/--end，否则 gen_tech.py 按测试期过滤会写 0 条）
python scripts/gen_tech.py --start 2024-03-15 --end 2024-08-07 `
  --price_folder dataset/CSMD50_feat/val/price --db <临时库>
python backtest/run_backtest_fusion.py --views tech --weights 1.0 --score_th 0.0 `
  --start 2024-03-15 --end 2024-08-07 --price_folder dataset/CSMD50_feat/val/price `
  --tag api_tech_val --db <临时库>

# 融合权重网格搜索（内存计算，不写库）
python scripts/calibrate_weights.py --step 0.05 --out docs/calib_weights.json
```

`result/CSMD50_w5_feat_bi` 是线上推理权重，重跑时**不要覆盖该目录**。
