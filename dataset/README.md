> 本目录下的行情与新闻数据来自公开学术数据集 **CSMD**，**不是**本项目采集，
> 也不适用本仓库根目录的 MIT 许可。

## 一、来源

| 项 | 内容 |
|---|---|
| 论文 | *CSMD: Curated Multimodal Dataset for Chinese Stock Analysis*，CIKM '25，pp. 6471–6475（华东师范大学 CILAB） |
| 代码/数据仓库 | https://github.com/ECNU-CILAB/LightQuant |
| 构成 | **CSMD50** = 上证 50 的 50 只成分股；**CSMD300** = 沪深 300 的 300 只成分股；2021–2024 |
| 数据内容 | 股价（Baostock 采集）+ 新闻文本（证券时报网 STCN，经 LLM 去噪与增强） |

## 四、本项目使用口径（三条限制，勿在论文中夸大）

1. **成分股是静态快照**：名单取自数据集构造时点，官方指数每半年调样，无法还原历史
   成分 → 存在幸存者偏差，已在论文限制章节声明。
2. **等权 ≠ 官方指数**：本项目基准用"成分股等权买入持有"，不含权重与分红；
   因此只能称"沪深300 成分股等权 / 上证50 成分股等权"，**不能称"沪深300 指数"**。
3. **价格口径**：`Close` 不复权（数据集的 `Adj Close` 与 `Close` 实测逐行相等，
   因子恒为 1），详见 `docs/复权口径与回测价格处理.md`。
